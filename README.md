# 🛠️ Mac Utility Apps (맥 유틸리티 프로그램 모음)

이 저장소는 macOS 환경에서 문서 작업과 텍스트 추출을 도와주는 편리한 자체 제작 유틸리티 프로그램들의 소스코드 저장소입니다. 

나의 코드 관리뿐만 아니라 다른 사람들도 구조를 이해하고 쉽게 사용할 수 있도록 상세 가이드를 제공합니다.

---

## 📂 프로젝트 구성 및 설명

두 프로그램은 구현된 **프로그래밍 언어의 특성**에 따라 파일 구성이 다릅니다.

### 1. 📊 그림, 표 추출기 (`그림 표 추출기` 폴더)
* **설명**: HWPX, DOCX, PDF 파일 등 다양한 문서 파일에서 그림(이미지)과 표 데이터를 자동으로 추출해 주는 프로그램입니다.
* **구성 파일**:
  * `extractor.py` ([코드 보기](https://github.com/ksdnews/my-mac-utilities/blob/main/그림%20표%20추출기/extractor.py)): Python으로 작성된 핵심 추출 로직 소스코드입니다.
  * `그림, 표 추출기.app`: 사용자가 편리하게 더블 클릭하여 실행할 수 있도록 패키징된 macOS 애플릿 앱입니다.
* **❓ 왜 이 폴더에는 빌드 파일(.sh)이 없나요?**
  * Python은 **인터프리터 언어**로, 컴파일(빌드) 과정 없이 코드가 작성된 텍스트 파일(`.py`)을 컴퓨터가 한 줄씩 읽어서 바로 실행합니다. 
  * 따라서 복잡한 컴파일 스크립트 없이 오직 하나의 파이썬 소스코드 파일(`extractor.py`)만 필요하며, 앱 번들 내부에서 이 파이썬 파일이 직접 호출되어 작동하는 간단한 구조입니다.

---

### 2. 📝 이미지 텍스트 변환 프로그램 (`이미지 텍스트 변환 프로그램` 폴더)
* **설명**: 화면 캡처 이미지나 사진 속의 글자를 광학 문자 인식(OCR)을 통해 텍스트로 인식 및 추출해 주는 프로그램입니다.
* **구성 파일**:
  * `mac_ocr_app.swift` ([코드 보기](https://github.com/ksdnews/my-mac-utilities/blob/main/이미지%20텍스트%20변환%20프로그램/mac_ocr_app.swift)): Apple Swift 언어와 네이티브 Vision 프레임워크를 기반으로 짜인 OCR UI 프로그램 소스코드입니다.
  * `build_app.sh` ([코드 보기](https://github.com/ksdnews/my-mac-utilities/blob/main/이미지%20텍스트%20변환%20프로그램/build_app.sh)): Swift 소스코드를 맥 실행 앱 번들로 만들어주는 빌드 자동화 쉘 스크립트입니다.
  * `이미지 텍스트 추출기.app`: 빌드 과정을 거쳐 최종 생성된 실행용 macOS 네이티브 앱입니다.
* **❓ 왜 이 폴더에는 여러 개의 파일이 있나요?**
  * Swift는 **컴파일 언어**입니다. 소스코드(`.swift`)를 작성한 뒤, 반드시 맥OS가 이해할 수 있는 기계어 실행 파일(바이너리)로 번역(컴파일)하는 과정을 거쳐야 합니다.
  * 이 컴파일 작업(`swiftc`)과 더불어 폴더 구조를 잡아 `.app` 앱 번들로 최종 포장하는 일련의 과정을 터미널 명령어로 직접 하면 복잡하기 때문에, 이를 한 번에 수행해 주는 **빌드 자동화 스크립트(`build_app.sh`)**가 추가로 필요한 것입니다.

## 💻 실행 및 설치 방법 (개발자용)

### 📊 그림, 표 추출기 실행 방법
파이썬 소스코드를 직접 실행하려면 아래 라이브러리 설치가 필요합니다.
```bash
pip install pdfplumber pypdf docx
python3 extractor.py
```

### 📝 이미지 텍스트 변환 프로그램 빌드 방법
Swift 소스코드를 컴파일하여 `.app` 파일을 새롭게 빌드하려면 아래 명령어를 사용합니다.
```bash
cd "이미지 텍스트 변환 프로그램"
chmod +x build_app.sh
./build_app.sh
```
실행이 완료되면 **바탕화면**에 자동으로 `이미지 텍스트 추출기.app` 파일이 새로 빌드되어 복사됩니다.
